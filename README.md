# Promosyonist Ürün Görselleri

Trendyol pazaryeri entegrasyonu için ürün görselleri.

Trendyol'un görsel çekici sunucularının bir kısmı Cloudflare'ın bot
korumasına (hata kodu 1010) takıldığı için görseller Cloudflare üzerinden
sunulamıyor. Bu depo, görsellerin jsDelivr üzerinden sunulması içindir.

Adres biçimi:

    https://cdn.jsdelivr.net/gh/umutkarasu/promosyonist-urun-gorselleri@main/products/ty/v5/<dosya>.jpg

Görsellerin asıl kaynağı promosyonist.com'dur; buradaki kopyalar
1200x1800 baseline JPEG olarak Trendyol'un görsel kurallarına göre üretilmiştir.
